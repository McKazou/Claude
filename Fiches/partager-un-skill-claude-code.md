# Partager un Skill Claude Code entre personnes, projets et sessions

**Symptôme / contexte** : j'ai un skill utile et je ne sais pas quel mécanisme utiliser selon que je veux le partager avec mon équipe, le réutiliser sur plusieurs de mes projets, ou m'assurer qu'il reste à jour partout où il sert.

**Quoi** : point d'entrée qui regroupe 3 scénarios de partage/synchronisation d'un skill, chacun détaillé dans sa propre fiche — celle-ci ne documente rien elle-même, elle aide à choisir la bonne fiche selon la situation. Suppose un skill déjà créé (voir [utiliser-un-skill-claude-code.md](utiliser-un-skill-claude-code.md)).

**Comment** :
- Le partager avec des coéquipiers sur le même dépôt → [partager-skill-equipe-git.md](partager-skill-equipe-git.md)
- Le réutiliser sur plusieurs projets qui n'ont pas de rapport entre eux → [reutiliser-skill-plusieurs-projets.md](reutiliser-skill-plusieurs-projets.md)
- S'assurer qu'une modification se propage bien à tous les usages → [synchroniser-skill-entre-usages.md](synchroniser-skill-entre-usages.md)

**Pourquoi** : ces trois besoins se résolvent par des mécanismes différents (git, réglage local, ou compte claude.ai) — les regrouper en un seul endroit évite de choisir le mauvais mécanisme faute d'y avoir pensé.

**Limites** : cette fiche ne remplace pas la lecture de la fiche cible — si un mécanisme change, éditer la fiche concernée, pas celle-ci.
